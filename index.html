데이터 연결

공공 API 인증키는 브라우저에 두지 않습니다. 인증키는 수집 스크립트나 API 프록시(Cloudflare Worker)에 넣고, 이 화면에는 그 결과 주소만 적습니다.

불러오는 방식
worker 폴더의 프록시를 배포한 주소입니다. 비워 두면 건너뜁니다.
collector 스크립트가 하루 한 번 만드는 JSON 파일입니다.
